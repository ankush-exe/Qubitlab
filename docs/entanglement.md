# Entanglement explained

Entanglement is a relationship between quantum systems that cannot be described by assigning each qubit an independent state. The two-qubit Bell state is $(|00> + |11>)/sqrt(2)$.

A common preparation is H on qubit 0 followed by CNOT with qubit 0 as control and qubit 1 as target. Measuring either qubit gives a random result, but the results always agree when the state is ideal.

Entanglement is not faster-than-light messaging. It is a shared structure in the joint state, and a measurement produces correlated results without letting us choose the outcome.
