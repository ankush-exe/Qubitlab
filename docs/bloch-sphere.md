# Reading a Bloch sphere

Every pure single-qubit state can be represented as a point on a sphere. The north pole is $|0>$ and the south pole is $|1>$. Points around the equator are balanced superpositions with different relative phases.

The polar angle controls the balance between the basis probabilities. The azimuthal angle controls relative phase. Rotations around the X, Y, and Z axes move the state vector in predictable ways.

The sphere describes one qubit only. A multi-qubit state can contain correlations that cannot be shown by giving each qubit its own independent sphere.
